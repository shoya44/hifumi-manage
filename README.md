# ひふみ 卓上オーダー

藤沢シーシャカフェ&バー「ひふみ」の店舗管理サブシステム。
お客さまが卓のQRコードからスマートフォンで注文し、スタッフがタブレットの
ダッシュボードで卓の状態と未提供の注文を一元的に把握できるようにする。

既存のWebサイト・予約システム・POSレジとは**完全に独立**しており、
既存システムへの改修は一切発生しない。会計は従来どおりレジで行う。

現在は **設計完了 / 試作版によるユーザー確認中** の段階。本実装は未着手。

## プロトタイプ

`prototype/index.html` をブラウザで開くだけで動作する(サーバー不要)。
お客さまの画面とスタッフの画面が並んで表示され、片方の操作がもう片方に反映される。

URLに `?table=2` を付けると、お客さま専用の全画面表示になる。

## 設計上の不変条件

以下は崩すとセキュリティ事故に直結する。変更前に必ず `docs/08_Project_Overview` 7章を読むこと。

1. フロントエンドにSupabaseクライアント・鍵を持たせない
2. 顧客系APIは必ず `X-Session-Token` を検証する(FastAPIのDepends経由)
3. RLSは全テーブル有効・ポリシー未作成のまま保つ
4. `orders` の部分UNIQUE `(table_id) WHERE status='Active'` を外さない
5. ステータス遷移の妥当性はサーバー側で検証する
6. 価格は注文時点の値を明細にスナップショットする
7. 価格は税込で保持する(店頭メニューが総額表示のため)

## セットアップ

`docs/05_開発・運用ガイド` 4章を参照。

```
1. Supabaseプロジェクト作成
2. db/schema.sql を実行
3. db/seed.sql を実行
4. スタッフのパスワードハッシュを生成して staff へINSERT
5. backend/ と frontend/ を起動
```
